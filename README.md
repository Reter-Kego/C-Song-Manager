# C-Song-Manager 🎵

一个使用 C 语言开发的简易歌曲管理系统（Song Management System）。

本项目通过命令行菜单实现歌曲信息管理，主要用于练习和巩固 C 语言中的结构体、结构体数组、函数、指针、字符串处理以及文件操作等知识。

## 一、项目功能

目前实现的主要功能包括：

| 菜单选项 | 功能说明 |
|---|---|
| 1 | 显示曲库中的全部歌曲 |
| 2 | 添加歌曲，支持连续录入 |
| 3 | 从文件重新读取歌曲数据 |
| 4 | 根据歌曲名称删除歌曲 |
| 5 | 根据歌曲序号删除歌曲 |
| 6 | 根据歌曲名称查找歌曲 |
| 7 | 修改歌曲名称、歌手或时长 |
| 8 | 按歌曲时长排序（升序 / 降序） |
| 9 | 按歌曲名称排序（升序 / 降序） |
| 10 | 统计歌曲总数、总时长和平均时长 |
| 11 | 收藏歌曲或取消收藏 |
| 12 | 查看已收藏的歌曲 |
| 0 | 退出程序 |

## 二、技术栈与知识点

本项目使用 C 语言开发，主要涉及：

- 结构体（Struct）
- 结构体数组
- 函数的定义、声明、调用与参数传递
- 指针及指针作为函数参数
- 字符串处理与 `string.h` 库函数
- 文件读写（File I/O）
- 冒泡排序及优化
- 顺序查找
- 菜单交互与输入处理
- 数据持久化

## 四、运行环境

- 操作系统：Windows
- 开发语言：C
- 编译器：GCC
- 开发环境：Dev-C++ 5.11

## 五、运行方式

1. 克隆或下载本项目。
2. 使用 Dev-C++ 打开 `歌曲管理系统.c`。
3. 编译并运行程序。
4. 根据命令行菜单提示进行操作。

也可以使用 GCC 编译：

```bash
gcc "歌曲管理系统.c" -o SongManager.exe
```

运行时，请确保 `C_Project.txt` 位于程序使用的当前工作目录中，以便正常读取和保存歌曲数据。

## 六、数据存储说明

本项目使用 `C_Project.txt` 保存歌曲数据，通过 C 语言文件操作实现数据持久化。

每首歌曲的数据包含四个字段：

| 字段 | 含义 |
|---|---|
| song | 歌曲名称 |
| singer | 歌手名称 |
| duration | 歌曲时长 |
| isFavorite | 收藏状态（0：未收藏，1：已收藏） |

数据采用文本形式存储，字段之间以制表符分隔。

程序启动时会尝试读取数据文件；添加、删除、修改、排序及收藏操作完成后，会尝试将当前曲库保存到文件中。

## 七、注意事项

1. **曲库容量限制**：当前程序最多存储100首歌曲，达到上限后无法继续添加。

2. **歌曲名称与歌手名称的输入限制**：当前使用 `scanf` 的 `%s` 格式读取，因此歌曲名称和歌手名称不能包含空格。例如，`Love Story` 不能作为一个完整字段输入。

3. **数据文件位置**：程序通过相对路径 `C_Project.txt` 读取和保存数据。请确保该文件位于程序运行时的当前工作目录中，否则可能出现读取或保存失败。

4. **数据文件格式**：请不要随意修改 `C_Project.txt` 的字段顺序或数据格式。每首歌曲应包含歌曲名称、歌手名称、时长和收藏状态四项数据，否则可能导致读取失败。

5. **重复歌曲删除规则**：根据歌曲名称删除时，如果存在同名歌曲，程序只会删除匹配到的第一首。若要删除指定的同名歌曲，建议使用按序号删除功能。

6. **数据覆盖与备份**：程序保存数据时会以写入模式打开 `C_Project.txt`，重新写入当前曲库。因此，如果需要手动修改数据文件，建议先备份，避免误操作造成数据丢失。

7. **运行目录问题**：如果程序无法读取数据文件，请检查 Dev-C++ 的程序运行目录设置，而不只是检查源代码所在目录。

8. **中文显示问题**：本项目包含中文菜单和提示信息。在不同 Windows 终端、编译器及字符编码环境下，中文显示效果可能有所不同。如果出现乱码，需要检查源文件编码、编译器编码处理及终端代码页是否兼容。

9. **保存失败提示**：如果程序提示保存失败，说明本次数据变更未能可靠地写入文件。建议检查文件路径和读写权限，并及时备份重要数据。
